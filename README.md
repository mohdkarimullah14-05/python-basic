# 50 Python Basic Questions

This repository contains 50 basic Python programming questions designed for beginners to practice fundamental concepts.

## About This Collection

These questions cover essential Python topics such as variables, data types, loops, conditionals, functions, and basic algorithms. They are ideal for anyone starting their Python learning journey or preparing for coding interviews.

1. Print "Hello, World!" to the console.
2. Write a program to add two numbers.
3. Find the largest of three numbers.

5. Calculate the factorial of a number.
6. Generate the Fibonacci sequence up to n terms.
7. Check if a string is a palindrome.
8. Reverse a string.
9. Find the sum of all elements in a list.

20. Check if two strings are anagrams.
21. Calculate the sum of digits of a number.
22. Find the second largest number in a list.
